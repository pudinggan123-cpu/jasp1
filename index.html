TENTANG PERUSAHAAN

Mengenal JASP lebih dekat

Solusi jaringan dan layanan server dalam satu tempat.

JASP (Jaringan Akses Sarana Pratama) adalah perusahaan bidang teknologi informasi yang berfokus pada layanan jaringan komputer dan server. Kami membantu kebutuhan perancangan, pemasangan, konfigurasi, serta pengelolaan layanan digital untuk sekolah, usaha, dan lingkungan kerja.

Produk dan layanan JASP meliputi Web Server untuk menjalankan situs web, Mail Server untuk layanan surat elektronik, serta MikroTik Hotspot untuk mengatur akses Wi-Fi dan voucher internet.
